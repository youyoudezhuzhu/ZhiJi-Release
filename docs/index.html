## 织记 v1.2.1a11

纸样使用记录改为「使用 / 复用」两态，另含物料选择与菜单细节优化。

### 本版内容
- **纸样使用/复用**：纸样每次最多用一份。添加使用记录时不再输入数量，改为「使用 / 复用」胶囊开关——使用则纸样数量减 1，复用则数量不变；使用记录列表直接显示「使用 / 复用」。
- **快捷复记**：材料清单中的纸样记为复用（0 份），下次按清单复记时不会误扣纸样库存；制作多件也只算一次。
- **保存为材料清单**：使用记录里含纸样时，自动生成的材料清单会把纸样记为复用。
- **物料选择器**：与手作库一致，同类型同名物料自动折叠文件夹（布料含材质、纸样含尺码）；需展开文件夹才能选中内部物料，搜索/切换类型会重新分组。
- **细节修复**：加号菜单各类条目改用独立识别色；三点菜单、用量单位切换等浮层菜单的圆角阴影不再被裁成直角。
- 使用记录「米 · 平米」双单位显示、安装权限胶囊按钮、编辑页横向转场等前序修改一并包含。
