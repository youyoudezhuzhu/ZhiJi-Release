## 织记 v1.2.1b1

本次更新：

- 首页底部新增面板收窄，选项与面板边缘留出更舒服的间距，面板整体更靠近加号。
- 底部悬浮导航的选中背景恢复为浅绿色，磨砂开关前后保持一致；选中图标与浅绿背景居中对齐，最外侧圆角与导航外弧同心。
- 首页右上角排序/设置、详情页返回与三点菜单等圆形图标按钮改为暖米色，和整体风格统一。
- 汇总“入库统计”移除多余的“全部价格 / 未填有效价格”和份数行；汇总“使用记录”的排序改为右上角排序菜单。
- 作品材料清单页左上角改为统一返回箭头。
- 下拉菜单、详情三点菜单、新增面板统一使用底部悬浮导航的玻璃材质，不再出现透明度不一致。
- 全部确认弹窗统一按钮：取消/放弃在左红底白字，保存/更新/确定在右强调色底白字。
- 详情备注输入框改为整宽居中，不再重复显示“备注”标签；在输入框外滑动页面会自动退出输入状态并收起键盘。
- 图片识别批量核对逐条详情：第一项左上角显示“返回”，可回到核对结果页修改识别内容；最后一项仍为“保存”。
- “更新材料清单”确认弹窗文案精简，并改为清晰的取消/更新胶囊。
