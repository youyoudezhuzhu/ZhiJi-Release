## 织记 v1.2.1a7

本版新增「外观工作室」与可拖拽底部导航。

### 本版内容
- **外观工作室**：设置 → 外观，集中配色预设/三色自定义、字体、背景与卡片纹理、磨砂与透明度；预览使用真实 Token 与公共组件，改动即时生效。
- **三色自定义**：只暴露主色/辅助色/点缀色，其余层级颜色自动推导；预设与自定义互不覆盖。
- **可拖拽底部导航**：底栏可直接拖动跟手，松手提交一次；中央新增按钮起手不接管拖动，点击/Tab 选中语义保留。
- 动效继续统一 BukuMotion，减少动态效果（系统 0×）即时到终点；未改业务数据与备份格式。
- 版本 1.2.1a7 / versionCode 9（高于 a6 的 8，可在线升级）。
