## 织记 v1.2.1b6

本次更新：

- 修复“更新材料清单”时误报“米数最多保留两位小数”：例如 0.68 米 ÷ 3 件生成单件清单后，系统派生精度不再套用用户输入的两位小数限制。
- 材料清单与快捷复记同步策略统一：手填精度和系统派生精度分开校验，整数单位、库存和单位规则不放宽。
- 修复纸样在“使用记录 → 材料清单 → 历史快捷复记”同步中可能被静默改成复用、并错误退库的问题。
- 更新清单后主动刷新当前快捷复记草稿，旧草稿保存前做版本校验，避免覆盖刚同步的数据。
- 库存、使用记录、作品写入统一协调，增加事务恢复保护，避免并发保存互相覆盖。
- 上一版裁剪页长按角度拨盘、导航同心圆、惯性、玻璃/非玻璃材质、圆形菜单底色等全部保留。
