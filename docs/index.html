## 织记 v1.2.1a9

本版主要做体积瘦身，并修复更新时间显示时区问题。

### 安装包体积：80.8MB → 28.0MB（约 -65%）
- 移除只给模拟器用的 x86/x86_64 OCR 原生库（真机全是 ARM），约省 23MB。
- 内置思源宋体改为子集（GB2312 6763 字 + 全部界面用字 + 常用符号），24.5MB → 4.7MB；生僻字回退系统字体。
- 开启 R8 代码压缩与资源压缩，剥离未使用的图标/代码；清理重复启动图与旧密度图标。
- 更新下载、安装校验、签名与数据格式均不变；在线更新包更小更快。

- 更新页「发布时间」之前直接显示 UTC，比北京时间慢 8 小时；现在按设备本地时区显示（如北京时间）。
- 顺带排查了全项目时间显示：创建/更新/使用/备份/反馈时间均按本地时区，未发现其它时区错位。
