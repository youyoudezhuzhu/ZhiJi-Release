## 织记 v1.2.1b3

本次更新：

- 图片识别批量导入：店铺名只在核对页作为纯文本，点击“逐条补全”时才匹配已有店铺标签；未匹配时弹窗确认，选“返回修改”不会进入下一步，选“确认生成”才批量新建。
- 同一张截图识别出的同店铺多行，修改其中一个店铺名会同步整组；核对页新增“厚度”人工属性，单选用现有厚度标签。
- 详情页/编辑页备注统一为“图标 + 备注 + 输入框”，文字纵向居中。
- 底部导航文字不再因固定高度被裁切；全局降低列表和长页面的滑动惯性。
- 详情三点菜单、首页/作品/汇总排序菜单等浮层重做主窗口玻璃材质，与底部新增面板一致，不再出现独立窗口的透明度差。
- 标签整理页右侧选中/编辑/删除/排序图标更紧凑，编辑/删除无圆圈背景；行胶囊只保留选中态和拖动排序态。
- 布料类型图标改为布片轮廓；其他细节与上一版全部保留。
